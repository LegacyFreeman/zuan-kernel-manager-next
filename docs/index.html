SetEdit

Prop Detected

Fitur di dalam SetEdit yang menyimpan snapshot properti perangkat sebagai baseline, lalu memberi tahu jika ada properti hilang, berubah, atau bertambah.

Butuh izinmu dulu. Snapshot hanya disimpan di penyimpanan privat aplikasi dan tidak dikirim keluar.

Safe

Tidak ada beda dari baseline.

Changes found

Hanya properti non-kritis yang berbeda.

Danger

Properti penting hilang atau berubah, misalnya ro.build.*, ro.product.*, ro.hardware, ro.secure, atau ro.debuggable.

Properti volatil seperti sys.*, net.*, dan init.svc.* diabaikan agar tidak memicu alarm palsu.

Akses

Tiga Mode Kerja

Pilih sesuai akses yang kamu punya. Semakin tinggi aksesnya, semakin banyak fitur yang terbuka.

Basic

Tanpa akses khusus

Fitur yang hanya melihat data.

ADB

Shizuku / wireless debugging

Akses level shell tanpa root.

ROOT

Akses penuh

Semua penyetelan tingkat kernel dan sistem.

Mode ROOT dan ADB bisa mengubah perilaku sistem. Salah konfigurasi dapat menyebabkan bootloop. Lakukan dengan risiko sendiri dan siapkan backup.

FAQ

Pertanyaan Umum

Jawaban singkat sebelum kamu mulai.

Apa itu ZKM Next?

Aplikasi Android untuk memantau dan menyetel kernel, GPU, thermal, baterai, aplikasi, dan tampilan dari satu tempat.

Apakah harus root?

Tidak wajib. Mode Basic hanya untuk melihat data, mode ADB lewat Shizuku membuka sebagian fitur, dan mode ROOT membuka semuanya.

Apakah data saya dikirim ke server?

Tidak. Data diproses lokal di perangkat dan tidak dikirim ke server cloud.

Apakah aman?

Perubahan tingkat kernel punya risiko. Gunakan backup, ubah nilai bertahap, dan pahami tiap pengaturan sebelum menerapkannya.

Kenapa ada menu yang tidak muncul?

Menu yang tidak didukung hardware atau kernel perangkatmu disembunyikan otomatis.

Siap Mengendalikan Perangkatmu?

Unduh ZKM Next dan mulai dari Dashboard. Ganti tombol ini dengan tautan rilis resmimu.
