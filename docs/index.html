Key Features

All kernel controls, in one app.

Built for power users: automatic node detection, unsupported controls hidden, and a consistent interface across all ROMs.

CPU & GPU Governors

Set governors, min/max frequency per CPU cluster, plus Qualcomm (KGSL) and MediaTek GPU control. Includes sched boost & uclamp.

cpufreqkgsluclamp

UFS Host Controller & Devfreq

Monitor UFS health, manage host controller clock gating, and configure devfreq nodes (DDR/DVFSRC, LLCC) on supported devices.

ufshcdevfreqstorage

ZRAM / Swap & Memory

Configure ZRAM size, compression algorithm, swappiness, dirty ratio, and cache pressure — complete with RAM, swap, and PSI monitoring.

zram0swappinessvm

Rootless Modes: Shizuku & Axeron

You don't always need root. Monitoring and basic features work via Shizuku or Axeron; full kernel actions require Root mode.

Kernel Flasher & Boot Backup

Flash kernel images with a careful workflow, including boot image backup & restore utilities so you always have a way back.

Technical Documentation

The sysfs & procfs interfaces ZKM Next accesses.

Every device is different. A feature appearing in the UI doesn't guarantee its node exists on your device — ZKM detects paths and hides unsupported controls.

Sysfs Overview

List of the main paths read or written by ZKM Next. RW = writable by the app (requires root), RO = read-only for monitoring.

CPU frequency policy RW

/sys/devices/system/cpu/cpufreq/policyN/

Governor and frequency limits per cluster. Clusters (policies) are auto-detected — 2, 3, or 4 tiers.

scaling_governorscaling_min_freqscaling_max_freqscaling_available_governorsscaling_available_frequencies

CPU per-core monitor RO

/sys/devices/system/cpu/cpuN/cpufreq/

Real-time frequency of each core for the dashboard and monitors.

scaling_cur_freq

Kernel scheduler RW

/proc/sys/kernel/

Scheduler parameters for performance/power-saving profiles.

sched_boostsched_util_clamp_minsched_util_clamp_maxsched_energy_awaresched_child_runs_first

Qualcomm LPM RW

/sys/devices/system/cpu/qcom_lpm/parameters/

Qualcomm CPU low-power mode control (if exposed by the kernel).

sleep_disabledprediction_disabled

Adreno GPU (KGSL) RW

/sys/class/kgsl/kgsl-3d0/

Clock, load, and behavior of the Qualcomm Adreno GPU.

gpuclkmin_gpuclkmax_gpuclkgpubusygpu_busy_percentagedevfreq/throttlingpreemptionbcl

Devfreq (GPU, DDR, bus) RW

/sys/class/devfreq/*

Governor and frequency limits for each detected devfreq device, including UFS/DDR on supported SoCs.

governormin_freqmax_freqcur_freqavailable_frequencies

ZRAM RW

/sys/block/zram0/

Size and compression algorithm of the compressed swap. Resizing requires resetting the ZRAM device.

disksizecomp_algorithmreset

Virtual memory RW

/proc/sys/vm/

Kernel memory management tuning.

swappinessdirty_ratiodirty_background_ratiovfs_cache_pressure

Memory stats & PSI RO

/proc/meminfo · /proc/pressure/

Monitor RAM, swap, and pressure stall information (cpu, memory).

meminfopressure/memorypressure/cpu

UFS host controller RW

/sys/devices/platform/soc/<addr>.ufshc/

Clock gating settings on the UFS host controller. Node names and addresses vary between SoCs.

clkgate_enable

Block device & I/O RW

/sys/block/<dev>/queue/ · /proc/diskstats

I/O scheduler, read-ahead, and live I/O statistics for the Storage screen.

schedulerread_ahead_kbnr_requests

Thermal zones RO

/sys/class/thermal/

Temperature readings from thermal zones; some devices also expose thermal profiles.

thermal_zone*/tempthermal_message/sconfig

Power supply RO

/sys/class/power_supply/battery/

Battery & charging statistics for monitoring and Charge Stats. Advanced charging control depends on vendor nodes.

capacitystatusvoltage_nowcurrent_now

LED & backlight (reference) RO

/sys/class/leds/

Standard Android nodes for LED and brightness. Part of the sysfs interface reference; ZKM doesn't rely on them for core features and their availability depends heavily on the device.

brightnessmax_brightness

MediaTek PPM / CPUFreq RW

/proc/ppm/ · /proc/cpufreq/

CPU power policy control on MediaTek SoCs (Helio / Dimensity) that expose these nodes.

ppm/enabledppm/policy_statuscpufreq_power_modecpufreq_cci_mode

MediaTek GPU & GED RW

/proc/gpufreq/ · /proc/gpufreqv2/ · /sys/kernel/ged/ · /proc/mali/

Frequency and DVFS for Mali/MediaTek GPUs.

gpufreq_opp_freqfix_target_opp_indexdcs_modedvfs_enablealways_on

Safety Notes & Warnings

ZKM Next performs privileged operations. Wrong values can cause instability, boot issues, overheating, or data loss.

There is no universal safe value

Kernel and thermal tuning have real hardware consequences. Don't blindly copy values from other devices.

Watch the temperature

Disabling thermal throttling or forcing maximum frequencies for extended periods can trigger overheating.

  1. Understand the parameterKnow what a node controls before changing it.
  2. Prepare a boot image backup & recoveryKeep a working boot image before flashing or heavy tuning — use the backup feature in Kernel Flasher.
  3. Change one group of settings at a timeThat way the cause of any issue is easy to trace.
  4. Don't blindly copy values from other devicesFrequencies, governors, and nodes differ between SoCs and kernels.
  5. Reboot and verify stabilityAfter major changes, restart and stress-test before making them permanent.

Installation Requirements

What you need before installing and fully using ZKM Next.

Root

Required for full kernel control. Compatible with:

  • Magisk
  • KernelSU
  • APatch
  • Other environments that provide su

Bootloader

The bootloader generally must be unlocked to gain root and to flash kernels/boot images. The unlock process may wipe data and varies by vendor.

SELinux

Some nodes depend on SELinux policy. If access is denied, the related feature won't work on that device.
